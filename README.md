# Web Dev

A web development project built with HTML.

## Description

This repository contains web development resources and projects created with HTML.

## Project Structure

- Static HTML files for web pages and components
- Clean and organized file structure for easy navigation

## Getting Started

### Prerequisites

- A modern web browser to view HTML files
- A text editor (VSCode, Sublime Text, etc.) for development

### How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/kissudon/web-dev.git
   ```

2. Navigate to the project directory:
   ```bash
   cd web-dev
   ```

3. Open the HTML files in your browser to view the content.
